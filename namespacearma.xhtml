Whole-matrix equality for compile-time sized Armadillo types.

Armadillo's own operator== yields an element-wise umat-like expression; this facade mirrors Eigen, whose operator== returns a plain bool, so the typed matrix equality assertions and the raw backend behave alike. More constrained than Armadillo's operator, so it wins overload resolution for fixed operands.
