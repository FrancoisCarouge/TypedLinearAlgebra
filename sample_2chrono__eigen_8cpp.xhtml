Detailed Description

Time safe linear algebra with std::chrono and Eigen.

Demonstrate a variety of linear algebra operations over a vector whose elements are std::chrono durations of distinct periods. This library composes Eigen as the matrix' linear algebra backend with indexes typed as std::chrono durations. This sample explicitly uses double precision floating point representation.
