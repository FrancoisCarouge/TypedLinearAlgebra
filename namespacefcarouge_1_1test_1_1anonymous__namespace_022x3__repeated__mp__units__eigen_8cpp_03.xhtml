const auto fcarouge::test::anonymous_namespace{2x3_repeated_mp_units_eigen.cpp}::test
Test
The by-type at accessor resolves the elements of a non-uniform, non-square two-dimension matrix whose types occur once, while the types repeated across several positions are not locatable. The once-occurring types sit in the last column so that a row/column transposition in the linear-index arithmetic yields a wrong type or an out-of-range position.
