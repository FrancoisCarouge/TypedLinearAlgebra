Detailed Description

Unit safe linear algebra with mp-units over std::array memory.

Demonstrate a variety of linear algebra operations with mp-units, std::linalg, and std::mdspan over std::array memory. The application owns the memory of every matrix in fixed-size standard arrays. This library composes a std::mdspan view of that memory as the matrix' linear algebra backend with index typed as mp-units types. No memory is allocated: the sample runs in a real-time context. This sample explicitly uses double precision floating point numbers.
