Detailed Description

Unit safe linear algebra with Au and Armadillo.

Demonstrate a variety of linear algebra operations with Au and Armadillo. This library composes Armadillo as the matrix' linear algebra backend with indexes typed as Au types. This sample explicitly uses double precision floating point numbers. This sample uses Armadillo linear algebra as the linear algebra backend. This sample uses Au types for the strongly typed units.
