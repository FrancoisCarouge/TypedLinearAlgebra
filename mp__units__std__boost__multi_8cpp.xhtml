Detailed Description

Unit safe linear algebra with mp-units over Boost.Multi memory.

Demonstrate a variety of linear algebra operations with mp-units, std::linalg, and std::mdspan over Boost.Multi memory. The application owns the memory of every matrix in Boost.Multi two-dimension arrays. This library composes a std::mdspan view of that memory as the matrix' linear algebra backend with index typed as mp-units types. The arrays are boost::multi::inplace_array, keeping their bounded memory in place, on the stack: the sample never allocates and runs in the real-time context. A nested braced list would allocate its rows: each array is constructed from its extents, then assigned its elements in row-major order. This sample explicitly uses double precision floating point numbers.
