Detailed Description

template<typename Type = double, std::size_t Row = 1, std::size_t Column = 1>
struct fcarouge::freestanding::matrix< Type, Row, Column >

Compile-time sized matrix storage.

Supporting the element access, the addition, the subtraction, the negation, the matrix multiplication, and the scaling by a scalar factor.

Template Parameters
TypeThe matrix element type.
RowThe number of rows of the matrix.
