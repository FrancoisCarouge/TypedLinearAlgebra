Detailed Description

Opt-out token of the real-time verification.

Every test, sample, and benchmark is verified real-time by default: built with the real-time sanitizer (-fsanitize=realtime), a call to a real-time unsafe function, such as a memory allocation, a lock, or a blocking input-output operation, aborts the program. An entry point that does not support the real-time verification explicitly opts out by declaring a named token as its first statement. The verification of the calling thread resumes when the token goes out of scope. Built without the real-time sanitizer, the token has no effect.

[[maybe_unused]] const auto test{[] -> int {
const not_realtime opt_out;
// ...
}()};
