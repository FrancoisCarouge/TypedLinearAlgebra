◆ all_of_distinct_positions()

template<typename... Matrices, typename Predicate>
auto fcarouge::typed_linear_algebra::internal::all_of_distinct_positions ( Predicate predicate) -> bool
nodiscardconsteval

Whether the predicate holds at each compile-time position of typed matrices of the same shape, as a row and a column std::integral_constant arguments, checked once per distinct combination of their element types.

The type of an element is the product of the types of its row and column indexes. Two rows whose index types are the same in every matrix hold the same element types, and so do two such columns: the predicate is evaluated at the first row of each distinct combination of row index types and the first column of each distinct combination of column index types only. A matrix of a few kinds of elements repeated over its rows and columns is checked at a cost that grows with its kinds of elements, not with its size. Evaluated at compile time only, as all_of_positions.

Precondition
Every matrix is of the same shape, and the predicate depends on the position only through the element types of the matrices.
Template Parameters
MatricesThe typed matrices whose element types the predicate checks.

template<typename To>
auto fcarouge::typed_linear_algebra::internal::converted_storage ( auto && from) -> decltype(auto)
nodiscardconstexpr

The storage of the typed matrix To keeping the values of from.

Elements of one scale need no conversion: their storage is passed as-is. Otherwise, each element converts through its type, read from an evaluation of the source, which may be an expression template, and written at its compile-time position. An element the storage cannot write keeps its default value, which the concept verified the conversion keeps.
