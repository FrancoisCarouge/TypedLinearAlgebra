Detailed Description

Unit safe linear algebra with nholthaus/units and Eigen.

Demonstrate a variety of linear algebra operations with the nholthaus/units library and Eigen. This library composes Eigen as the matrix' linear algebra backend with indexes typed as units::unit containers. This sample explicitly uses double precision floating point numbers as the underlying representation.
